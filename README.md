# «Альфа Рядом»

Конкурсное решение по масштабированию выдачи дебетовых карт Альфа-Банка.

## Главные файлы

- `Alfa_Ryadom_Final_Draft.pptx` — редактируемая презентация: 18 основных слайдов и 8 приложений.
- `09_Scenariy_prezentacii.md` — содержание и логика защиты.
- `capacity_plan.csv` — помесячный план объёмов и точек.
- `unit_economics.csv` — unit-экономика каналов.
- `10_Reestr_istochnikov_i_dopushcheniy.md` — источники, допущения и ограничения утверждений.
- `01_...08_*.md` — подробная доказательная база каждого блока.

## Контрольные цифры

- 10,0 млн успешных выдач.
- 5,5 млн альтернативных и 4,5 млн традиционных выдач.
- 70% альтернативного потока в М12.
- 679 ₽ — расчётная стоимость альтернативной выдачи.
- 1,231 млн — резерв альтернативной мощности.

Все тарифы, мощности и конверсии, не заданные кейсом или официальным источником, являются учебными допущениями и должны быть подтверждены пилотом.

## Пересборка презентации

```bash
.venv/bin/python build_presentation.py
```

Генератор создаёт `Alfa_Ryadom_Final_Draft.pptx`.
